File Descriptions
=================

Core Application:
- application.fam: Defines app metadata, dependencies, build config
- bootpicker.c: Main entry point, app lifecycle, UI setup
- bootpicker_i.h: Shared structures, app context definition

Profile System:
- profiles.h/c: JSON I/O, profile validation, config management
- Handles loading/saving profiles from SD card
- Implements atomic file writes for safety

HID System:
- hid_sender.h/c: USB keyboard emulation wrapper
- Sends F12, arrow keys, ENTER
- Manages USB mode switching

Scene System:
- bootpicker_scene*: UI screens and navigation
  * Main: F12 spam control, profile selection
  * Profile Editor: Create/edit profiles, calibration
  * Settings: Global configuration

View System:
- bootpicker_main_view: Custom view with spinner animation
- Uses Flipper's view model for efficient rendering

Key Features Implemented

✅ F12 Spam Loop (FuriTimer-based)
